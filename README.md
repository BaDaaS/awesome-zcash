## Wallets

- [Zashi](https://electriccoin.co/zashi/) – Mobile wallet for iOS and Android developed by Electric Coin Co., with a focus on simplicity and shielded transactions.
- [Nighthawk Wallet](https://nighthawkwallet.com/) – Open-source mobile wallet for Android and iOS, supporting shielded and transparent addresses.
- [YWallet](https://ywallet.app/) – Fast, privacy-focused mobile wallet with support for multiple Zcash accounts and note encryption.
- [ZecWallet Lite](https://zecwallet.co/) – Desktop and mobile light client wallet with full shielded address support.
- [Unstoppable Wallet](https://unstoppable.money/) – Non-custodial multi-asset mobile wallet with Zcash support.

## SDKs & Libraries

- [librustzcash](https://github.com/zcash/librustzcash) – Rust library implementing Zcash cryptographic primitives and consensus rules.
- [zcash-android-wallet-sdk](https://github.com/Electric-Coin-Company/zcash-android-wallet-sdk) – Android SDK for building Zcash light-client wallets.
- [zcash-swift-wallet-sdk](https://github.com/Electric-Coin-Company/zcash-swift-wallet-sdk) – Swift SDK for building Zcash light-client wallets on iOS and macOS.
- [zcash-light-client-ffi](https://github.com/Electric-Coin-Company/zcash-light-client-ffi) – Foreign-function interface exposing the Zcash Rust wallet backend to mobile platforms.
- [Zcash JavaScript / WebAssembly](https://github.com/nicowillis/zcash-wasm) – WASM bindings for Zcash cryptographic operations in the browser.

## Block Explorers

- [Zcash Block Explorer](https://zcashblockexplorer.com/) – Full-featured block explorer for the Zcash mainnet.
- [Blockchair Zcash](https://blockchair.com/zcash) – Multi-chain explorer with Zcash mainnet data and advanced filtering.

## Infrastructure & Nodes

- [zcashd](https://github.com/zcash/zcash) – The reference full-node implementation of Zcash (C++).
- [zebra](https://github.com/ZcashFoundation/zebra) – Independent Zcash full-node implementation written in Rust, developed by the Zcash Foundation.
- [lightwalletd](https://github.com/zcash/lightwalletd) – gRPC server that provides compact block data to light-client wallets.

## Mining

- [Mining Zcash – Official Guide](https://z.cash/mining-zcash/) – Official documentation on how to mine Zcash.
- [ZCash.flypool.org](https://zcash.flypool.org/) – One of the largest Zcash mining pools.
- [2Miners ZEC Pool](https://2miners.com/zec-mining-pool) – Zcash mining pool with transparent statistics and PPLNS payouts.

## Developer Tools

- [Zcash Developer Hub](https://zcash.github.io/developers/) – Official developer documentation, guides, and API references.
- [ZIP (Zcash Improvement Proposals)](https://zips.z.cash/) – Specification documents for Zcash protocol changes and features.
- [Zcash Protocol Specification](https://zips.z.cash/protocol/protocol.pdf) – The formal protocol specification document.
- [Orchard](https://github.com/zcash/orchard) – Rust implementation of the Orchard shielded protocol introduced in the NU5 upgrade.
- [Halo2](https://github.com/privacy-scaling-explorations/halo2) – Proving system used in Zcash's Orchard shielded protocol.
