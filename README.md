# awesome-zcash
Curated list of Zcash related projects.


## Tachyon

- Origin blog post from Sean Bowe: https://seanbowe.com/blog/tachyon-scaling-zcash-oblivious-synchronization.

## Developer Tools

- [zcash-mcp](https://github.com/Frontier-Compute/zcash-mcp) - MCP server exposing 22 Zcash tools for AI agents. Shielded send, memo decode, ZAP1 attestation, proof verification, MPC wallets, cross-chain swaps. `npx @frontiercompute/zcash-mcp`
- [zap1-verify](https://github.com/Frontier-Compute/zap1-verify) - Rust crate and EVM contracts for on-chain verification of ZAP1 Merkle proofs. Deployed on Ethereum, Arbitrum, Base, Hyperliquid, Sepolia.

## Crosslink

- Book about the project: https://shieldedlabs.github.io/zebra-crosslink/.
